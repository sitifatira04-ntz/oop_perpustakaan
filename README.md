# OOP Perpustakaan

Aplikasi perpustakaan mini berbasis teks untuk tugas OOP Semester 3.

## Fitur

- Menambah koleksi (Buku, Majalah, DVD) dan anggota
- Peminjaman dan pengembalian
- Perhitungan denda otomatis sesuai jenis koleksi

## Konsep OOP yang Digunakan

- Class, Object, Constructor
- Encapsulation & Property
- Abstract Class & Inheritance
- Polymorphism (method overriding)
- Class Variable, Class Method, Static Method
- Composition (Peminjaman memiliki Item)
- Magic Method (`__str__`, `__eq__`, `__len__`)
- Custom Exception
